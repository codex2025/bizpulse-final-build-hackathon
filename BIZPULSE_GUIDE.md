## 🚀 Quick Start: Local Host
Run these three services in separate terminals to start the platform.

### 1. Backend (NestJS API)
*Connects to your local SQLite database and handles all business logic.*
```powershell
cd backend
npm install
npm run start:dev
```
🔗 **Access**: `http://localhost:3001/api`

### 2. Frontend (React + Vite)
*The premium Red/White glassmorphic user interface.*
```powershell
cd frontend
npm install
npm run dev
```
🔗 **Access**: [http://localhost:5173](http://localhost:5173)

### 3. AI Service (Python / FastAPI)
*The intelligence engine for contract analysis and financial simulations.*
```powershell
cd ai-service
# Create and activate virtual environment
python -m venv venv
.\venv\Scripts\activate
# Install requirements
pip install -r requirements.txt
# Run the service
python -m uvicorn app.main:app --reload
```
🔗 **Access**: `http://localhost:8000/docs`
